# User Manual

## Public Landing Page
- Open the platform home page to review value proposition, key controls, and SOS Liberia visual context.
- Use `Launch platform demo` to enter the operational console.

## Login And Role Switching
- Choose a demo user from the session selector.
- Use the sidebar role switcher to simulate approvals, procurement actions, or audit review.

## Procurement
- View requisitions with budget status and approval state.
- Approve pending PRs when using the approver role.
- Create a PO from an approved PR.
- Review RFQ bids and award outcomes.
- Review invoice match status and exceptions.

## Finance
- Review budget availability and commitment balances.
- Authorize pending payment requests.
- Reconcile initiated payments once bank confirmation is available.
- Escalate reminders or exceptions through the notification queue.

## Documents
- Search records by title, metadata, OCR text, or transaction reference.
- Upload evidence with metadata and related entity reference.
- Download audit packs for linked procurement cases.
- Archive records under retention policy control.

## Audit
- Review immutable activity events.
- Export CSV evidence for investigations or donor review.
