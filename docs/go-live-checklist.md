# Go-Live Checklist

## Technical Readiness
- Production environment provisioned
- TLS certificates installed
- Database backups tested
- Object storage bucket created
- Monitoring and alerting enabled
- Identity provider configured

## Functional Readiness
- Approval matrix validated
- Supplier categories and due-diligence checklist loaded
- Budget ledgers imported
- Retention policies approved
- Key users trained
- UAT sign-off completed

## Operational Readiness
- Support contacts circulated
- Incident process agreed
- Backup and restore owners named
- Release rollback plan documented
- Hypercare schedule approved
