# Support Plan

## One-Year Technical Support Scope
- Business-hours incident response for application issues
- Bug fixes for delivered scope
- Minor configuration changes to workflows, thresholds, and retention settings
- Deployment support for patch releases
- Quarterly service review meetings

## Service Targets
- Severity 1: response within 2 hours
- Severity 2: response within 8 business hours
- Severity 3: response within 2 business days
- Severity 4: bundled into scheduled release cycle

## Operational Activities
- Monthly health review
- Quarterly restore test verification
- Quarterly access review and RBAC audit
- Semiannual donor and compliance evidence review

## Handover Artifacts
- Source code repository
- Deployment scripts
- Environment templates
- Architecture and admin documentation
- UAT and training records
