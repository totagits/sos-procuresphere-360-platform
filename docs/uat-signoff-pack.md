# UAT Sign-Off Pack

## Core Test Scripts
- Create PR with donor and budget coding, route for approval, and convert to PO
- Close RFQ, review supplier bids, record evaluation, approve award, and create PO
- Receive goods or confirm service, submit invoice, run 3-way match, and authorize payment
- Upload supporting document, search by OCR text, and download audit pack
- Export audit log and verify approval history for the full case

## UAT Roles
- Requester
- Procurement Officer
- Approver
- Finance Controller
- Warehouse Officer
- Auditor
- Supplier Portal User

## Exit Criteria
- All mandatory workflows pass
- No open severity-1 or severity-2 defects
- Admin and end-user training completed
- Backup and restore walkthrough completed
- Named business owners sign the release decision
